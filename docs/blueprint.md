# **App Name**: ContainerPilot

## Core Features:

- Container Listing: List all running Docker containers and display their current versions.
- Version Checker: Compare current container versions against available image versions using a tool powered by a LLM to determine if an update is needed.
- Automated Updates: Automatically update outdated containers with the latest image versions.
- Notifications: Alert users when containers are updated, or when updates fail.
- Configuration: Enable or disable container auto updates and customize polling time through the UI.

## Style Guidelines:

- Primary color: Deep indigo (#4B0082) for a sense of authority and reliability, evocative of infrastructure.
- Background color: Light grey (#F0F0F0) to ensure readability and minimize distraction.
- Accent color: Vivid violet (#8A2BE2) to highlight important notifications and actionable items.
- Body and headline font: 'Inter' sans-serif, chosen for its modern and neutral appearance.
- Use simple, clear icons from a set like Font Awesome to represent container states and actions.
- A clean, tabular layout for container information with clear status indicators.
- Subtle transitions and loading animations to improve user experience during updates.
